# Comparison protocol (Versions 1, 2 and 3)

- **Version 1:** one ChatGPT chat does all five stages alone. It is scored on accuracy only. It cannot earn an official Design or Finish lock.
- **Version 2:** the parent plus six child Grok bots. It seeks an official lock under these gates and is described as a same-family role split.
- **Version 3:** this design, Version 2 plus a ChatGPT outside review at the question lock (OR1) and the finish (OR2). It seeks an official lock under these gates. It uses a ChatGPT chat separate from Version 1's, so Version 1 stays ChatGPT alone and Version 2 stays Grok alone.

## Fairness
Every version gets the same case pack, rules and stopping rules. No version sees another's work or the key. Version 3's outside reviewer sees only Version 3's own OR packets. The case must be fresh to both.

## Scoring
Scoring happens only after the versions being compared are sealed. The earlier key preparer from the ChatGPT (Version 1) side holds the private key and scores every version blind. That scorer is not a live role. Live roles never see the key. The scorecard is written in advance:
1. Accuracy on four dimensions: target/population; numbers and memberships (money to the cent, percents to 2 decimals); interpretation and claim ceiling; action and rationale.
2. Error list, with error types and whether they are shared.
3. Wall-clock time and operator hands-on time.
4. Usage and cost.

5. Version 3 only: OR1/OR2 issues raised, how many were fixed, how many blocking issues reached the owner, and any OR-SKIPPED.

No winner is declared mid-run. Report limits plainly: one case is not a general accuracy claim.

## Run cap
- One attempt per version on Case B.
- A maximum of 3 repair rounds.
- Stop and report after about a day of work per side.
- If a side is blocked (for example by a limit or an outage), wait and retry up to 3 times, then report.
